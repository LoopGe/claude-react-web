# Native P1.5 — Thinking, Effort and Steering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Native sessions support (a) extended thinking — request config, signed thinking blocks kept in model history, and live `setMaxThinkingTokens`; (b) effort level and fast mode — `output_config.effort` and `speed: 'fast'` + the fast-mode beta header, with live `applyFlagSettings`; (c) steering — `enqueueSupplement` injecting a wrapped guidance message before the next API round, delivered through the existing broker/`MESSAGE_STEERED` path and persisted for resume.

**Architecture:** Thinking: the canonical IR learns `signature_delta` and `redacted_thinking`, and both the live loop and log replay keep thinking blocks ONLY when they carry a signature (or redacted data) — unsigned blocks are stripped (the API rejects them). `buildRequestBody` emits the snake_case `thinking` config. Effort/fast mode: `buildRequestBody` adds `output_config.effort` and `speed: 'fast'`; the streamer adds `anthropic-beta: fast-mode-2026-02-01` when fast mode is on. Steering: an explicit `steeringOpen` flag gates admission; at the top of every API round the session-side drain appends the `session/supplement` log event (storing the WRAPPED text), flushes, fires `onSupplementDelivered`, and returns entries the loop appends to `history`.

**Tech Stack:** TypeScript ESM (`.js` suffixes), Node 20, existing `server/effort-capability.ts`, vitest, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-09-native-session-persistence-design.md` (add a P1.5 section in Task 5).

## Global Constraints

- No behavior change for `server/providers/claude/**` EXCEPT the requeue-order fix in `requeueSteeredLeftovers` (record the prompt uuid BEFORE `enqueueUserMessage`, matching `dispatchUserMessage`; a no-op for claude because pairing happens at echo time) and extracting the supplement wrapper to a provider-neutral module (re-exported from `server/providers/claude/steering.ts`).
- Thinking blocks are kept in model history ONLY when signed (non-empty `signature`) or redacted (`data` present). Old logs with unsigned thinking are stripped, as today.
- `thinking` wire shape is snake_case: `{type:'adaptive'}`, `{type:'enabled', budget_tokens: N}`, `{type:'disabled'}`. Bare `{type:'enabled'}` at create maps to `{type:'adaptive'}` (no valid bare-enabled wire form exists). `budget_tokens` is clamped to `[1024, max_tokens - 1]` (max_tokens is 16384 today).
- Effort is `output_config.effort` (not a top-level `effort`); fast mode is `speed: 'fast'` plus `anthropic-beta: fast-mode-2026-02-01`. Both are OMITTED at request-build time when the current model does not support the value (`effortLevelsForModel` / `supportsFastModeForModel`).
- `applyFlagSettings` accepts `skillOverrides`, `effortLevel`, and `fastMode` (null clears each); every other key still throws.
- `setMaxThinkingTokens(tokens, display?)`: null→adaptive, 0→disabled, N→enabled; `display` is forwarded only when it is `'summarized'` or `'omitted'` (`'highlights'` is dropped — not in the wire union).
- `supportedModels()` returns the SDK camelCase shape (`value`, `displayName`, `supportsFastMode`, `supportsEffort`, `supportedEffortLevels`) sourced from `opts.profile?.modelList ?? config.modelList`, on `NativeSession`.
- Steering admission is `this.steeringOpen === true` (opened at prompt consumption, closed by `noteTurnSettled`) — never `turnAbort !== null`. `onSupplementDelivered` fires only for entries actually inserted for a request, with `boundary: 'PreToolUse'`.
- `session/supplement` stores the WRAPPED text the model saw; `historyFromEvents` replays it verbatim at its log position (no re-wrapping) and resets the open tool-result group; the reader/search/seq backfill exclude it (not searchable after restart), and the sidecar owns the UI bubble.
- The nested Agent runner never receives the supplement drain dep (matching claude's `agent_id` exclusion).
- No new dependencies; diagnostics through `createLogger`; focused tests first, full gate before the final commit.

## Review Focus

1. **Signed-retention rule** — a thinking block with a signature survives in the next request's messages and in replay; an unsigned block is stripped in both (but still emitted in the UI frame).
2. **Request shapes** — `thinking`, `output_config.effort`, `speed`, and the beta header are exactly right; absent config emits none of them; bare-enabled maps to adaptive; budget is clamped; unsupported-model effort/fastMode is omitted.
3. **Live controls** — `setMaxThinkingTokens` and `applyFlagSettings` change the NEXT request (live mutable fields, not `opts` snapshots); null clears; unknown keys throw.
4. **Steering timing** — admission only while `steeringOpen`; injection happens before the NEXT request (not the current one); `onSupplementDelivered` fires once per injected entry; leftover supplements drain for the manager's turn-end requeue.
5. **Supplement durability** — `session/supplement` stores the wrapped text and replays it verbatim at its log position (resetting the tool-result group), never as a duplicate UI bubble.
6. **Capabilities** — `supportsThinkingControl`, `supportsEffortLevel`, `supportsFastMode`, `supportsSteering` flip to true and the routes stop 501ing; `fast_mode_state` appears on BOTH the init and result frames.

Each line gets a test in the owning task.

## Execution decisions

- **Signed-only retention** (thinking blocks are kept in model history only when signed/redacted). Unsigned blocks are stripped everywhere, matching the API's rejection of unsigned thinking; old logs therefore lose no valid content.
- **Wire shapes are literal**: `thinking` uses `budget_tokens`; effort is `output_config.effort`; fast mode is `speed: 'fast'` + `anthropic-beta: fast-mode-2026-02-01`. Bare `{type:'enabled'}` at create maps to adaptive (no valid bare-enabled wire form); `budget_tokens` is clamped to `[1024, max_tokens - 1]`; `display` forwards only `'summarized'`/`'omitted'`.
- **Unsupported-model effort/fastMode is OMITTED at build time** (using `effortLevelsForModel`/`supportsFastModeForModel`), so a model switch cannot turn a pinned incompatible level into a 400. This is a deliberate clamp, not a deferred error.
- **`fast_mode_state` is intent-based** (`on` when fastMode is on), stamped on BOTH the init frame and the result frame so the chip is visible before the first turn ends.
- **Supplements are log events, not renderable lines** (`session/supplement`): replay injects them into model history at their log position (resetting the tool-result group), and the sidecar owns the UI bubble. They are not searchable after restart.
- **Steering admission is `steeringOpen`**, opened at prompt consumption and closed by `noteTurnSettled` — never `turnAbort !== null`, which would strand a supplement landing between the pump's turn-end drain and `pumpLoop`'s `finally`.
- **The nested Agent runner never receives the supplement drain dep** (matching claude's `agent_id` exclusion).
- **Deferred:** `Options.effortLevel` per-model downgrading (native omits instead of clamping to the nearest supported level), `Query.setMaxThinkingTokens` display values beyond `'summarized'`/`'omitted'`, `supportedModels` SDK-reported fields beyond the three the wire exposes, `Options.plugins` fast-mode eligibility rules (model_not_allowed etc.), and generic `/settings` keys the native provider still rejects (autoCompactEnabled/agent/hooks/sandbox/memory — fail loudly as today).
