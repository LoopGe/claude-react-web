# 粗野主义主题（Brutalist Skin）设计文档

日期：2026-10-28　状态：**待发起人批准**（builder 审阅已完成；3 项补充决策已并入 §5/§6/§7）

## 1. 意图（为什么做）

为 claude-react-web 增加一套经典粗野主义 UI 主题。设计过程从三个候选方向（A 混凝土 / B 瑞士黑白 / C 新粗野）中选定 **C 新粗野（Neo-Brutalism）**，并确认**浅色、深色都做**，深色取 **A 反色纸面** 方案。

成功的样子：切到该皮肤后，整个应用像一块贴满告示牌的工作台——厚黑边、硬投影、贴纸徽章、高饱和三色、零圆角、零模糊；切回其他皮肤时现有主题零损伤。

## 2. 目标

- 新增皮肤 **BRUTALIST**（`data-skin="brutalist"`），含浅/深两套配色，经 AppearancePanel SKIN 行切换，随时切回。
- **全表面覆盖**：会话栏、聊天面板、消息气泡、工具卡、working bar、输入框、设置面板、Git/任务面板、命令面板、弹窗、右键菜单、toast、tooltip、权限卡、子代理卡等。半覆盖 = 出戏 = 失败。
- 结构规则（该皮肤下全局生效）：圆角全部归零；边框 2–3px 实线；投影一律无模糊硬投影（实色偏移）；徽章/贴纸轻微旋转（约 -2°～1.5°）。
- 排版：标签、按钮、徽章用系统栈**重字重 + 大写 + 紧字距**；**消息正文保持普通无衬线**（可读性优先）；代码/计时器/等宽场景照旧。
- 该皮肤下**关闭**：毛玻璃/背景模糊、渐变、发光、柔和阴影、透明背景（transparency 强制 off）。
- **保留不动**：布局、信息密度、交互、动效节奏（既有动画照常播放，只是长在新表面上）。

## 3. 非目标

- 不引入外部 webfont。
- 不改布局、信息架构、交互逻辑；不动默认主题与 Anthropic 皮肤的 Poppins/Lora。
- 不为该皮肤定制图标集、KaTeX 内部样式、EasterEgg 游戏美术（跟随 token 即可）。
- 不做"粗野 lite"混合态（残留玻璃/圆角的半粗野是反目标）。

## 4. 反目标（做到即失败）

- 局部漏改：任何表面残留圆角、模糊、渐变、柔影。
- 正文可读性下降（正文变成重字重大写或过度字距）。
- 破坏现有皮肤/主题（dark/light、Default/Glow/Anthropic/HC）的切换或观感。
- 组件 CSS 里散落硬编码色值（违反仓库"颜色一律走主题 CSS 变量"的规则）。

## 5. 约束

- 所有颜色经 theme CSS 变量；新色在深/浅两套（`:root` 与 `[data-theme="light"]`，或皮肤两套等价块）都有定义。
- 实现以 **token 覆盖为主**，不做逐组件结构改造（已定）。
- 强调色在该皮肤下**固定为黄/橙/蓝三色体系**，不跟随用户自定义 accent 换色（已定）；accent 换色器在该皮肤下隐藏或禁用。
- **语义状态色独立保留**（设计者拍板）：`--danger`/`--ok`/`--warn`、diff 增删色、搜索高亮及其 `*-text` AA 姊妹值继续表达"红=错误/危险、绿=成功"的语义，**不并入**黄/橙/蓝；只做高饱和 + 硬边风格调谐。错误态必须与橙色主操作一眼可分。
- `npm run typecheck` / `test` / `lint` 全绿；浅深两套逐表面目测。

## 6. 已定决策

**发起人拍板：**

1. 视觉方向 = **C 新粗野**：纸面米黄 + 3px 黑边 + 7px 无模糊硬投影 + 贴纸徽章（微旋转）+ 黄/橙/蓝。
2. **浅、深都做**；深色 = **A 反色纸面**（黑底 + 米白粗边硬投影，同一套黄/橙/蓝贴纸，工具卡反转）。

**设计者拍板（对话中明示、发起人未反对；可在审阅时推翻）：**

3. 落位：AppearancePanel SKIN 行新增 "BRUTALIST"，与 Default/Glow/Anthropic 并列，`data-skin="brutalist"`。
4. 双轴分工：**皮肤管结构**（边/影/圆角/字体/关闭玻璃），**现有 `data-theme` 管色板**（浅 = C 纸面，深 = A 反色纸面）。
5. transparency 在该皮肤下强制关闭；毛玻璃/渐变/发光 token 在该皮肤下失效。
6. 字体不新增：系统栈重字重（西文 `Arial Black`/900 回退，中文回退 PingFang SC / 微软雅黑 Bold）；正文普通无衬线；等宽照旧。
7. 全表面一次定全（可分期落地，但设计规格一次定）。
8. 动效保留：working bar 脉冲、抽屉滑入、按压缩放等照旧。
9. **背景图在该皮肤下锁定**（设计者拍板）：走 Anthropic/HC 同款 `isBackgroundLocked` 路径，背景图选择器隐藏；纸面工作台不能透出照片/渐变背景。

## 7. 视觉规格（mockup 定稿值；实施时可微调以满足 AA 对比度）

### 浅色 · C 纸面

| 角色 | 值 |
|---|---|
| 纸面底 | `#f5f1e6` |
| 面板/卡片 | `#ffffff` |
| 墨线（边框/正文） | `#111111` |
| 贴纸黄（选中会话 / working / 强调） | `#ffe600` |
| 橙（主操作 SEND / 状态点 / PLAN 徽章） | `#ff4d00` |
| 蓝（用户气泡 / 侧栏标题条 / 会话组头） | `#3b5bff` |
| 硬投影 | `#111111`，容器 7px、贴纸 2–3px，无模糊 |
| 工具卡 | 黑底 `#111` + 黄字 `#ffe600` |

### 深色 · A 反色纸面

| 角色 | 值 |
|---|---|
| 底 | `#141312` |
| 面板 | `#1e1c19` |
| 输入面 | `#26231f` |
| 线/字 | `#f2ede0` |
| 硬投影 | `#5f5a52`，同浅色规格 |
| 黄/橙/蓝 | 与浅色同值 |
| 工具卡 | 反转：米白底 `#f2ede0` + 深字 `#141312` |
| 主操作 | 橙底白字 |

### 元件语言（两套共用）

- **徽章/chips**：2px 边 + 小硬投影 + 轻微旋转（-2°～1.5°，PLAN/模型徽章等装饰性贴纸才有旋转）。
- **选中会话**：黄贴纸（黄底 + 墨边 + 硬投影）。
- **标题条**（侧栏 SESSIONS、会话组头）：蓝底白字。
- **消息气泡**：用户 = 蓝底白字贴纸；助手 = 纸面/面板色 + 墨边 + 硬投影。均零圆角。
- **输入框**：白/输入面底 + 厚边；SEND = 橙贴纸。
- **working bar**：黄贴纸 + 橙状态点（脉冲动画保留）。
- 圆角：全部 0。

### accent 兜底映射（设计者拍板）

角色表未覆盖的 `--accent` 消费者一律按此落位，不得逐组件即兴取色：

- **填充/高亮面**（选中态、进度条填充、高亮块）= 黄 `#ffe600`，必须配墨色描边或墨色文字。
- **主操作**（按钮填充、开关开启态）= 橙 `#ff4d00`。
- **文字级/细线条**（链接、focus ring、`::selection`、active 下划线、搜索命中）= 蓝 `#3b5bff`（对纸面实测约 4.3:1，过 UI 组件 3:1 门槛）。
- **黄色永远不做文字色、不做细描边**（对纸面约 1:1，必挂 AA）——只做大面积填充 + 墨边。
- 其余模式徽章（fast 等）在贴纸系统内取黄/橙/蓝。

## 8. 留给实施者

- token 命名与映射：`--radius-*` → 0、边框宽度/色、`--card-shadow`/`--modal-shadow`/`--overlay-shadow` → 硬投影、`--glass-*` 关闭路径、是否新增 `--bt-*` 族。
- 色值 AA 微调（仓库惯例：状态色配 `*-text` AA 姊妹值）。
- 逐组件落点清单：working bar、权限卡、QuestionDialog、CommandPalette、toast/tooltip、context menu、滚动条、focus ring、空状态、Markdown 内标题/引用/表格等。
- accent 写入 `<html>` 的机制在该皮肤下禁用/固定的接线；AppearancePanel 皮肤行文案与 transparency 开关的隐藏。
- 分期落地顺序与测试/目测清单。

## 9. 验收

- SKIN 行出现 BRUTALIST，切换即时生效、可切回，现有主题零损伤。
- 浅深两套符合第 7 节；无残留圆角/模糊/渐变/柔影。
- `npm run typecheck`、`npm run lint`、`npm run test` 全绿。
