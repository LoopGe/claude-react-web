The Liquid Glass effect uses SVG displacement maps to physically bend background light through a simulated curved surface, creating real optical refraction

★ Uses SVG <feDisplacementMap> as backdrop-filter — currently Chrome-only. Falls back to blur-only on other browsers.

① Surface Profile A height function describes the glass curvature (convex dome, lip, or concave dip). The surface normal determines refraction angle.
② Displacement Map Pixel colors encode the 2D offset vector: R = horizontal shift, G = vertical shift. Generated on a canvas from the surface profile.
③ SVG Filter <feDisplacementMap> reads the map and shifts each backdrop pixel. Combined with blur, specular highlight, and screen blending.
④ backdrop-filter CSS The filter applies to everything behind the element — real-time refraction of the animated background orbs.
